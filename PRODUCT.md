# <H∞D>

Пользователь: <Переезжающий — 18–27 лет, переехал в новый город один и живёт во временном жилье (хостел, посуточная аренда). Заходит каждый день 1–2 недели, пока выбирает район.>.
Зачем: <помочь переезжающему выбрать район для постоянной жизни до поиска квартиры, чтобы он не снимал жильё «наугад» на Авито или ЦИАН.>.
Ключевой сценарий: <Переезжающий отвечает на анкету из 5 вопросов: бюджет, где работает или учится, как ездит, какой образ жизни, что важно рядом → LLM получает ответы и данные по районам и возвращает топ-3 района. У каждого есть объяснение «почему подходит» и «на что обратить внимание» → Переезжающий открывает карточку района, читает отзывы жителей и добавляет район в избранное → Он нажимает «Искать квартиру» и попадает на Авито или ЦИАН по ссылке с уже выбранным районом → выбран один район, и поиск квартиры открыт>.
Экраны: <Анкета, Топ-3 района (результат LLM), Карточка района с отзывами, Избранное и сравнение районов>.
Основная сущность: <основная сущность - район, поля: название, город, описание, средняя аренда, оценки по 5 критериям (транспорт, безопасность, цены, зелень, инфраструктура), плюсы, минусы, ссылка на поиск. К району привязан Отзыв (текст, плюсы, минусы, статус «на проверке / опубликован / отклонён»). Его проверяет модератор.>.
LLM-функция (одна): подбор и объяснение. Модель получает анкету и данные районов и возвращает топ-3 с объяснением простым языком, на «ты». Других LLM-функций нет.
Не в этом курсе: <платежи и подписки; официальная интеграция с API Авито и ЦИАН (только внешняя ссылка); проверка жителей по геолокации и документам, приглашения через месяц; карты в реальном времени и push-уведомления; вход через соцсети; несколько городов (только один город-пилот).>.
